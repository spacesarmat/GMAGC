# GMAGC: автообновление (0.6.0). Дизайн

Дата: 2026-09-21. Статус: дизайн утверждён в диалоге (режим «по кнопке», проверка включена по умолчанию), реализация начата.
Продолжение `2026-09-21-gmagc-android-client-design.md`. Готовы: ядро, ПК-приложение с поиском и сервером, Android-клиент (v0.5.x).

## 1. Цель

Приложение само узнаёт, что на GitHub вышла новая версия, и предлагает её поставить. На ПК (Windows, macOS) установка идёт по кнопке из самого приложения; на Android приложение ведёт на загрузку APK. Всё остальное остаётся офлайн: сеть нужна только этой проверке.

## 2. Решения

| Вопрос | Решение |
|---|---|
| Источник | GitHub Releases этого репозитория: `GET https://api.github.com/repos/spacesarmat/GMAGC/releases/latest` (без предрелизов и черновиков, без токена); версия = тег `vX.Y.Z` |
| Режим | **По кнопке**: приложение только предлагает, ставит после нажатия «Обновить»; тихой установки нет |
| Когда проверять | Через несколько секунд после запуска, в фоне, не чаще раза в 24 часа; кнопка «Проверить обновления» проверяет сразу |
| Отказ | Нет сети, ошибка или лимит GitHub: тихо ничего не показывается (для ручной проверки показывается причина) |
| Настройки | `check_updates` (по умолчанию `true`, выключатель на экране), `skipped_version`, `last_update_check` |
| Целостность | Только HTTPS; хосты `github.com` и `*.githubusercontent.com` (проверяется каждый переход); SHA-256 сверяется с файлом `.sha256` из того же релиза; размер и распаковка ограничены. Сборки не подписаны, а сумма лежит в том же релизе: она защищает от повреждённой загрузки, но не от взлома аккаунта GitHub (подпись релизов вне объёма) |
| ПК: установка | Скачать архив, проверить сумму, распаковать во временную папку, закрыть приложение, скрипт-помощник заменяет файлы (прежняя версия остаётся резервом), запускает новую; при сбое замены возвращает прежнюю |
| ПК: не вышло | Папка приложения недоступна для записи, неизвестная раскладка, сбой проверки: показывается ссылка на страницу релиза, приложение не ломается |
| Android | Полоса «Доступна версия…», «Скачать» открывает APK в браузере (загрузка и установка средствами системы); тихая установка на Android без особых прав невозможна |
| Данные | Настройки и индекс лежат в каталоге данных пользователя, вне папки приложения, обновление их не трогает |
| Проверка без GitHub | Переменная `GMAGC_UPDATE_URL` (только адрес на `127.0.0.1` или `localhost`) подменяет источник для тестов и живой проверки |

## 3. Общая логика (`gmagc_common/updates.py`, только стандартная библиотека)

- `parse_version(text) -> tuple[int, int, int] | None` (`v0.5.1`, `0.5.1`), `is_newer(candidate, current) -> bool`.
- `Asset(name, url, size)`, `ReleaseInfo(version, tag, notes, page_url, assets)` c `from_api(dict)`; черновики и предрелизы отбрасываются.
- `pick_assets(release, platform) -> tuple[Asset, Asset | None] | None`: файл и его `.sha256` для `windows` (`GMAGC-desktop-windows-<версия>.zip`), `macos` (`GMAGC-desktop-macos-<версия>.zip`), `android` (`GMAGC-android-<версия>.apk`).
- `parse_sha256(text) -> str | None` (формат `sha256sum`).
- `is_allowed_url(url, allow_local=False) -> bool` (HTTPS и допустимые хосты).
- `fetch_latest(current_version, timeout=8.0, url=None) -> ReleaseInfo | None` (`None`, если новой версии нет), `UpdateCheckError` с понятным текстом; `User-Agent: GMAGC/<версия>`, ответ не больше 1 МБ.
- `check_due(last_check, now, interval=24 ч) -> bool`.

## 4. ПК (`gmagc_desktop/update/`)

- `installer.py`: `download(asset, sha_asset, dest, progress, cancel) -> Path` (потоковая загрузка, счёт SHA-256, проверка размера, отмена), `stage(zip_path, dest_dir) -> Path` (безопасная распаковка без выхода за папку, проверка, что внутри есть исполняемый файл приложения), `current_executable()`, `install_dir()`, `is_writable(path)`, `write_helper(...)` / `launch_helper(...)`.
- Помощник Windows: пакетный файл: ждёт завершения процесса, `robocopy` прежней версии в резервную папку, `robocopy` новой поверх, при ошибке возвращает резерв, запускает `gmagc-desktop.exe`. macOS: shell-скрипт с `ditto` и `open`.
- `service/settings.py`: поля `check_updates`, `skipped_version`, `last_update_check`.
- Экран: полоса «Доступна версия X (у вас Y)» с кнопками «Обновить», «Что нового» (страница релиза), «Пропустить»; прогресс загрузки и отмена; сообщение перед перезапуском; в подвале «Проверить обновления» и выключатель «Проверять обновления при запуске».

## 5. Android (`gmagc_mobile/`)

- `updates.py`: `UpdateNotice` и проверка раз в сутки (время в `SharedPreferences`), тот же `fetch_latest`.
- Экран: полоса «Доступна версия X» с «Скачать» (`UrlLauncher`) и «Пропустить»; выключатель «Проверять обновления» и кнопка «Проверить сейчас» на экране подключения.

## 6. Тестирование

- Общая логика: версии и порядок (`0.10.0` новее `0.9.9`), разбор ответа GitHub, предрелизы, выбор файла по платформе, разбор суммы, разрешённые адреса, интервал; `fetch_latest` на локальном сервере (200, 404, лимит 403/429, не JSON, слишком большой ответ, таймаут).
- ПК: загрузка (верная и неверная сумма, обрыв, отмена, чужой хост при редиректе), безопасная распаковка (`..`, абсолютные пути), скрипт-помощник (содержимое, кавычки в путях с пробелами и кириллицей), недоступная папка, экран на заглушках (полоса, «Пропустить», ручная проверка, выключатель).
- Живая проверка на Windows от начала до конца: сборка 0.5.x и локальный «GitHub» (`GMAGC_UPDATE_URL`) с версией новее и настоящим архивом; замена файлов, перезапуск, запуск новой версии, резерв.
- Не проверяется без устройств: установка на macOS и скачивание APK на телефоне (проверяет пользователь).

## 7. Вне объёма

Подпись релизов и проверка подписи, тихая установка, обновление Android изнутри приложения, дельта-обновления, каналы (beta), откат по кнопке.
