# Гобо-колёса из библиотеки GMAGC в типы приборов grandMA2/MA3

Дата: 2026-09-24. Статус: утверждено пользователем (оба способа выбора гобо, PNG в MA3 автоматически, сначала MA2).

## Зачем

Сейчас диапазоны колеса гобо в экспорте — обычные `ChannelSet` без слотов, а `<Wheels/>` пуст. В пультах у колеса нет картинок гобо. Библиотека гобо уже есть на ПК (GMAGC ищет по ней), нужно связать её со слотами колёс.

## Формат (по эталонным файлам пользователя)

- **MA2** (`shehds@380w_beam@19_channel.xml`): `Wheels index="N"` (N — число колёс) → `Wheel index subattribute attribute feature preset` → `Slot index media_name [media_filename]` с вложенным `<media width="64" height="64"><Image>` — 16384 байта сырых RGBA (base64). `ChannelFunction` получает `wheel="<номер колеса с 1>"`, каждый `ChannelSet` — `slot_index`, `slot_from="0"`, `slot_to="0"`.
- **MA3** (`shehds@380w beam.xml`): `Wheels/Wheel Name/Slot Name Guid Color [MediaFileName]` + `DependencyExport/…/GoboImage` (файл в `MediaPools.Gobos`); `ChannelFunction Wheel="…"`, `ChannelSet WheelSlotIndex`. Сам PNG лежит в папке `gobos` пульта.

## Решения

| Вопрос | Решение |
|---|---|
| Выбор гобо на телефоне | Оба способа: поиск по имени и по фото (поиск по фото уже есть) |
| PNG для MA3 | ПК кладёт PNG гобо в папку MA3 сам, как типы приборов |
| Порядок | Сначала MA2, затем MA3, каждый со своей проверкой импортом в пульт |
| Картинка в профиле | `Gobo(name, path, thumb)`; `thumb` = base64(zlib(RGBA 64×64)) — общий пакет (только стандартная библиотека) без разбора PNG, экспорт MA2 берёт сырые пиксели |

## Шаги

1. Модель `Gobo` у диапазона + JSON + экспорт MA2 (слоты колёс). Тесты на синтетических картинках.
2. Методы ПК: поиск гобо по имени, превью гобо (`thumb`), поиск по фото уже есть (`/api/match`).
3. Экран телефона: в диапазоне канала-колеса кнопка «Гобо из библиотеки» (имя или фото) → слот. Проверка пользователем: импорт в MA2.
4. Экспорт MA3 + запись PNG в папку `gobos` MA3. Проверка импортом в MA3.
5. Релиз (v1.2.0 после шагов 1–3, v1.3.0 после шага 4).

## Ограничения

Слотом становится каждый диапазон колеса (как в эталоне у цветов). Вращение/шейк слотов, фасеты призм и цвета слотов колёс цвета — вне этой работы.

## Статус и решения по MA3 (шаг 4)

- Шаги 1–3 (модель, MA2, поиск и выбор гобо на телефоне) выпущены в v1.2.0.
- **MA3:** `Wheels/Wheel Name="Gobo{n}"` со слотом на каждый диапазон; у слота с гобо — `MediaFileName="GOBO/GMAGC/имя_хеш.png"` и `DependencyExport/Dependency/GoboImage` (`FilePath="GMAGC"`, `FileName="имя_хеш.png"`). `ChannelFunction` получает `Wheel` и `PhysicalTo` = число слотов, `ChannelSet` — `WheelSlotIndex` (с 1), `HasPhysical="Yes"`, `PhysicalTo="0.0000"`. Одинаковые колёса разных режимов — одно колесо.
- **Картинки:** ПК записывает PNG (из файла библиотеки, `source` в профиле) в `gma3_library\fixturetyperesources\gobos\GMAGC\` рядом с `fixturetypes`; если папка типов задана вручную и называется иначе — в её подпапку `gobos\GMAGC\`. Пути из профиля проверяются (только `GMAGC/имя.png`); нет файла — пропуск `no_gobo:ma3:<имя>`, тип всё равно записывается.
- Проверено: структура совпадает с эталоном пользователя по всем атрибутам (кроме необязательного `CreatedBy`). Не проверено импортом в MA3 и тем, что MA3 находит картинки в `fixturetyperesources\gobos`.
- «Поделиться файлом» с телефона для MA3 картинок не содержит (библиотека на ПК): слоты будут без картинок; для картинок использовать «Отправить на ПК».
