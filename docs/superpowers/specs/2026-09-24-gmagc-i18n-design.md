# GMAGC: русский и английский языки (v1.0). Дизайн

Дата: 2026-09-24. Статус: подход одобрен пользователем («язык авто по системе, смена языка без перезагрузки»).

## 1. Цель

Интерфейс ПК-приложения и телефона на русском и английском. Язык по умолчанию — «Авто» (по системе), можно выбрать «Русский» или «English». **Смена языка применяется сразу, без перезапуска.**

## 2. Решения

| Вопрос | Решение |
|---|---|
| Механизм | Собственный модуль `gmagc_common/i18n.py` (стандартная библиотека): `t(текст, **параметры)`, `plural(n, ru=(…), en=(…))`, `set_language`, `current_language`, `register(язык, словарь)`. Внешних библиотек и файлов `.po` нет |
| Ключ | Русский текст (как в gettext). Английские переводы — словари «русский → английский» рядом с кодом (`lang_en.py` в общем пакете и в каждом приложении). Непереведённая строка показывается по-русски. Тесты продолжают проверять русские фразы (язык по умолчанию в тестах — русский) |
| Полнота | Тест разбирает исходники (`ast`) и требует английского перевода для каждого `t("…")` с литералом |
| Авто | Язык системы: `ru…` — русский, любой другой известный — английский, определить не удалось — русский. На ПК: `locale` и, на Windows, `GetUserDefaultLocaleName`; на телефоне: событие `on_locale_change` Flet и `locale`. Выбор хранится в настройках ПК (`language`) и в SharedPreferences телефона (`gmagc.language`) |
| Смена без перезапуска | Приложение пересобирается на тех же службах: страница очищается, интерфейс строится заново на новом языке, открывается экран «Настройки». Теряется только временное состояние экрана (текущее фото и результаты поиска на ПК, снимки этой сессии на телефоне); индекс, сервер, соединение с ПК, профили и настройки сохраняются |
| Сообщения сервера | Сервер отдаёт код ошибки, а текст телефон подбирает на своём языке (готовый русский текст остаётся запасным вариантом и для старых версий) |
| Не переводится | Данные пользователя (названия каналов профилей, имена гобо, пути), логи, служебные скрипты (`phone_sim.py`, `export_ma*.py`), внутренние комментарии. Новые каналы из шаблонов получают названия на языке интерфейса |
| Документация | `README.md` (русский) и `README.en.md` |

## 3. Порядок работ (каждый шаг — отдельный PR)

1. Ядро `i18n` и настройка языка (ПК и телефон), без переводов.
2. Пересборка интерфейса и выбор языка на ПК.
3. То же на телефоне.
4. Переводы интерфейса телефона.
5. Переводы интерфейса ПК.
6. Общие сообщения (проверка профиля, обновления, поддержка автора, протокол) и ошибки сервера кодами.
7. `README.en.md`, тест полноты переводов, релиз v1.0.0.

## 4. Риски

- Определение языка телефона: Flet 1.0 не даёт документированного способа прочитать системную локаль при запуске, поэтому «Авто» на телефоне сначала опирается на `locale` и событие смены локали; если язык определить не удалось, берётся русский, а выбор «English» работает всегда. Проверяется на реальном телефоне.
- Пересборка интерфейса «на живую» на ПК затрагивает нативное окно Flet: проверяется вручную (нативные клики автоматикой недоступны).
- Объём: около 600 строк интерфейса и общих сообщений; перевод пишет Claude, проверять формулировки на английском стоит пользователю.
