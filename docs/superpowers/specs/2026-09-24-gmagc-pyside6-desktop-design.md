# ПК-приложение GMAGC на PySide6

Дата: 2026-09-24. Ветка: `feat/pyside6`. Решения пользователя: переносится **только ПК-приложение** (телефон остаётся на Flet), сборка **PyInstaller**, перенос **заменой по экранам**, улучшения — после переноса.

## Зачем

Flet 1.0.0 в нативном клиенте не рисует часть раскладок (SPACE_BETWEEN, Container(expand=True)-спейсеры), не поддерживает перетаскивание файлов из ОС и тянет Flutter-клиент. Qt даёт нативные виджеты, диалоги, буфер обмена с картинками и системный трей.

## Что не меняется

Всё ниже интерфейса не зависит от Flet и переносится как есть: `service/` (поиск, индекс, настройки, экспорт профилей, автозапуск), `server/` (HTTP-сервер для телефона), `matcher/`, `library/`, `scan/`, `update/`, `gmagc_common`. Телефонное приложение и его сборка (Flet) не затрагиваются.

## Архитектура

Пакет `gmagc_desktop/qt/`:

| Модуль | Ответственность |
|---|---|
| `theme.py` | Тёмная палитра из `gmagc_common.theme` в виде QSS; крупный текст масштабирует шрифт |
| `icons.py` | Иконки навигации как встроенные SVG (без внешних зависимостей) |
| `controller.py` | `AppController(QObject)`: состояние и логика без виджетов — индексация, поиск, поправки, сервер, история; сигналы Qt; фоновые задачи через подменяемый исполнитель (в тестах — синхронный) |
| `window.py` | `MainWindow`: боковая панель, хлебные крошки, стек экранов, статус-строка, полоса обновлений |
| `screens/` | Экраны «Поиск», «Телефон», «Библиотека», «Настройки» — только виджеты, всё поведение через контроллер |
| `app.py` | `run()`: QApplication, язык, служба, окно; `main.py` пока остаётся Flet до последнего шага |

Потоки: тяжёлое (индексация, поиск) идёт в `QThreadPool`, результат возвращается сигналами в главный поток. Виджеты из рабочих потоков не трогаются.

Тесты: `QT_QPA_PLATFORM=offscreen`, `pytest-qt`; логика — на контроллере без окна, виджеты — точечно. Старые Flet-тесты экранов удаляются вместе с экраном, тесты службы/сервера/матчера остаются.

## Порядок (экран за экраном, каждый — отдельный коммит с тестами)

1. Каркас: тема, иконки, контроллер, окно с навигацией, экран «Библиотека» (выбор папки, индексация с прогрессом и отменой, статус, подсказка первого запуска).
2. «Поиск»: выбор фото, вставка из буфера (Ctrl+V), превью, поправки фото и проекции, результаты карточками, «показать в папке», «это не то», копирование пути.
3. «Телефон»: сервер, QR, код доступа, адреса, история запросов.
4. «Настройки»: язык (сборка заново на лету), крупный текст, автозапуск, число результатов, папки MA2/MA3, ключ облака, экспорт/импорт настроек, проверка ядра, лог, поддержка.
5. Полоса обновлений и окно поддержки.
6. Точка входа, PyInstaller (Windows и macOS), установщик Windows, автообновление, CI (Qt в тестах), удаление Flet из ПК-приложения.

## Риски

- Установщик и автообновление (`update/installer.py`) рассчитаны на структуру `flet build`; под PyInstaller папка и имя exe другие — проверить на шаге 6.
- CI на Linux: Qt в offscreen требует системных библиотек (`libegl1`, `libxkbcommon0` и др.).
- Размер сборки: Qt Essentials ≈ 60–100 МБ, ожидается меньше Flutter-клиента + Python.
