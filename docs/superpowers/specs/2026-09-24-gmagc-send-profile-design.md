# GMAGC: отправка профиля прибора на ПК (этап 4). Дизайн

Дата: 2026-09-24. Статус: реализовано по просьбе пользователя («приступай», «поделиться файлом, а не текстом»).
Продолжение `2026-09-24-gmagc-fixture-editor-design.md`. Готово: редактор, экспорт в MA3 (v0.8.0) и MA2 (v0.9.0), «Поделиться» файлами.

## 1. Цель

Кнопка «Отправить на ПК» на экране профиля: ПК получает профиль по уже существующему соединению и сам кладёт типы приборов в папки grandMA3 и grandMA2, без копирования файлов вручную.

## 2. Решения

| Вопрос | Решение |
|---|---|
| Метод | `POST /api/fixtures`, тело — JSON профиля (`profile_to_dict`), до `MAX_PROFILE_BYTES` = 1 МБ, код доступа как у остальных методов |
| Ответ | `FixtureUploadResult(written=((пульт, путь), …), skipped=(сообщение, …))` |
| Ошибки | `bad_profile` 400 (не профиль или не готов к экспорту; текст — причина), `no_target` 409 (некуда писать), `too_large` 413, `bad_request` 400 (нет Content-Length) |
| Куда писать | Папка из настроек ПК (`ma3_fixture_dir`, `ma2_fixture_dir`; создаётся при необходимости), иначе найденная: `ProgramData\MALightingTechnology\gma3_library\fixturetypes` и самая новая `ProgramData\MA Lighting Technologies\grandma\gma2_V_*\importexport` (версии сравниваются числами). Вне Windows автопоиска нет — папки задаются в настройках |
| Частичный успех | Если одного пульта нет, второй пишется, а пропуск возвращается в `skipped`; если нет обоих — `no_target` |
| Имена файлов | Только из общих `profile_file_name`/`ma2_file_name` (без разделителей пути), повторная отправка перезаписывает те же файлы |
| Безопасность | Пути берутся только из локальных настроек ПК, не из запроса |
| Телефон | `GmagcClient.send_fixture`, `ProfileEditor.on_send_to_pc`, итог зелёным текстом («Записано на ПК: …»), ошибки красным; без подключения — подсказка подключиться |
| ПК-окно | На экране «Настройки» два поля с папками, подсказка показывает найденную папку по умолчанию |

## 3. Проверка
Тесты: протокол, запись файлов (`tests/desktop/test_fixture_export.py`, все пути во временных папках, реальные папки MA не трогаются), сервер (`tests/server/test_api_fixtures.py`), клиент и редактор телефона, поля настроек на ПК. Вручную: отправка с телефона на ПК с MA3/MA2 и импорт в пульты.
